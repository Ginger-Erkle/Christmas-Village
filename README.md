# Binary Christmas Village 🎄

A cozy animated Christmas village with a cybersecurity twist, built entirely with Python's standard-library **Tkinter**.

## Features
- Animated `0` and `1` snowfall
- Binary Christmas trees with twinkling ornaments
- Cozy glowing cabins and festive rooftop lights
- Crescent moon, stars, mountains, and snowbanks
- A clean dark winter aesthetic
- Pause with **Space**, exit with **Esc**

## Run

Requires Python 3 with Tkinter installed.

```bash
python christmas_village.py
```

On some Linux distributions, install Tkinter separately (e.g. `sudo apt install python3-tk`).
